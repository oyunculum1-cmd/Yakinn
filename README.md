# Yakın — internetsiz mesajlaşma
Android Studio ile aç (File > Open), iki telefona kur, ikisinde de uygulamayı aç: birbirini otomatik bulur.

Özellikler: sohbet, sesli arama, kalıcı geçmiş, açılış animasyonu, profil düzenleme.
Sadece Yakın'da: Meydan (menzildeki herkese ortak sohbet), kaybolan mesajlar (30 sn),
dürtme (karşı telefon titrer), ruh hali ve avatar rengi (yakındakilere görünür), radar.
Görüntülü arama ve uzak mesafe (sunucu gerekir) sonraki sürüm.
